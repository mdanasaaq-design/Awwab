# Awwab Design Direction

Awwab should feel like a personal command center rather than a generic chatbot.

## Design goals
- Fast assistant access
- Clear current tasks and priorities
- Visible pending approvals
- Useful activity history
- Project status
- Simple settings
- Mobile-first daily workflows

## Web/laptop
The information architecture should leave room for Assistant, Projects, Tasks, Research, Automations, Activity and Settings.

## Android
Prioritize Assistant, voice/text interaction, Notifications, Today view, Approvals and Quick Actions.

## Interaction principles
- Show what Awwab is about to do before sensitive actions.
- Make approval state unmistakable.
- Surface failures rather than hiding them.
- Keep common actions short.
- Avoid unnecessary visual complexity.

The visual system will be finalized with the first client implementation.
