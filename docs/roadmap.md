# Awwab Roadmap

## Strategy

Build the smallest trustworthy system that can progressively become more capable. Do not skip validation for flashy features.

## Phase 0 — Foundation and validation (P0)

Deliver identity/device trust, Firestore boundaries, approvals, audit, emulator tests, development Firebase, CI, threat model and evaluation harness.

Exit when foundation tests pass and the development environment works end-to-end.

## Phase 1 — Assistant Core (P1)

Deliver assistant endpoint, provider interface, model router, conversation persistence, context selection, structured plans, tool registry, policy engine, approval gate, execution/verification and web assistant UI.

Exit when Awwab can reliably complete a small set of safe tasks with auditability.

## Phase 2 — Personal Context (P1)

Memory, preferences, goals, tasks, Today, reminders and follow-up.

Exit when continuity is useful without uncontrolled memory growth.

## Phase 3 — Research and Project Intelligence (P1)

Web/file research, citations, GitHub integration, project context and approved development workflows.

## Phase 4 — Tool Platform (P2)

Versioned tools, scopes, budgets, retries, idempotency, health monitoring, integration lifecycle and optional MCP interoperability.

## Phase 5 — Automation and Proactivity (P2)

Scheduler, events, bounded jobs, kill switch, proactive suggestions, notification budget and approval policies.

## Phase 6 — Voice and Multimodal (P2)

STT, TTS, real-time voice where justified, file/image understanding and Android voice workflows.

## Phase 7 — Advanced Agent (P3)

Long-running research, advanced planning, sandboxed computer use, selective multi-agent workflows and agent-to-agent interoperability.

These remain experiments until they demonstrate user value and safety.

## Phase 8 — Optimization

Latency, routing, cost, caching, retrieval quality, battery/network behavior, observability and reliability.

## Release gate

A phase is complete only when acceptance criteria, automated tests, security review, evaluation suite and documentation are complete and observed results are recorded.
