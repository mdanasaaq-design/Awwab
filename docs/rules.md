# Awwab Engineering Rules

1. Inspect before changing.
2. Plan before implementing.
3. Obtain owner approval for scoped development work.
4. Keep changes focused.
5. Preserve existing work.
6. Never invent repository state, tests, commits, deployments or tool results.
7. Never commit secrets.
8. Keep privileged execution server-side.
9. Use least-privilege permissions.
10. Require confirmation for sensitive actions.
11. Document meaningful architectural decisions.
12. Validate with available automated checks.
13. Distinguish verified results from assumptions.
14. Do not create meaningless changes for activity metrics.
15. Keep product documentation synchronized with implementation.
16. Treat Android platform restrictions as real constraints.
17. Prefer official APIs and supported integrations.
18. Record known limitations and unresolved decisions.
