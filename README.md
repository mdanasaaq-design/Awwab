# Awwab

Awwab is a personal AI operating assistant designed for secure, cross-platform use across laptop/web and Android.

## Status
**Phase:** Foundation  
**Status:** Initial repository setup

Awwab is being built incrementally with security, maintainability, explicit approval for sensitive actions, and clear separation between clients, backend services, AI orchestration, and tool integrations as core principles.

## Planned clients
- Web/laptop interface
- Native Android application

## Planned backend
Firebase is the planned backend platform, subject to documented technical and cost validation.

## Core principles
- Security and least privilege
- User approval for sensitive actions
- No secrets in client applications
- Evidence-based implementation
- Small, meaningful changes
- No fabricated test, deployment, or tool results
- Documentation aligned with implementation

See `docs/` and `project/` for the current product and engineering plan.
